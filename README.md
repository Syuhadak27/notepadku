Catatan — Notes Offline

Aplikasi catatan digital berbasis HTML, CSS, dan JavaScript yang dirancang untuk menyimpan, mengelola, dan mengedit catatan secara lokal tanpa memerlukan backend.

✨ Fitur

📝 Manajemen Catatan

- Membuat dan mengedit catatan.
- Menggandakan catatan.
- Menyematkan catatan penting (Pin).
- Menandai catatan sebagai favorit.
- Mengarsipkan catatan.
- Memindahkan catatan ke folder.
- Menghapus dan memulihkan catatan melalui Sampah.
- Menghapus catatan secara permanen.
- Menampilkan waktu pembuatan dan pembaruan catatan.

✍️ Rich Text Editor

- Format teks tebal, miring, dan garis bawah.
- Pengaturan warna teks dan sorotan.
- Gaya teks paragraf, judul, subjudul, dan heading.
- Daftar berpoin dan bernomor.
- Checklist interaktif.
- Menambahkan tautan.
- Menyisipkan tabel.
- Menyisipkan gambar.
- Menyisipkan rekaman audio.
- Pintasan Markdown untuk pemformatan teks.
- Undo dan redo.
- Pencarian teks di dalam editor.
- Statistik karakter, kata, dan estimasi waktu baca.

📁 Folder dan Organisasi

- Membuat dan mengelola folder.
- Mengelompokkan catatan berdasarkan folder.
- Menambahkan tag pada catatan.
- Menelusuri catatan berdasarkan tag.
- Menampilkan semua catatan, favorit, arsip, dan sampah.
- Mengurutkan dan mengubah tampilan koleksi catatan.

🔍 Pencarian

- Pencarian berdasarkan judul catatan.
- Pencarian berdasarkan isi catatan.
- Pencarian berdasarkan tag.
- Sorotan teks yang cocok dengan kata kunci.
- Akses pencarian melalui pintasan keyboard.
- Riwayat pencarian terakhir.

🎙️ Rekaman Audio

- Merekam suara langsung dari aplikasi.
- Mendengarkan rekaman sebelum menyimpan.
- Menyisipkan rekaman ke dalam catatan.
- Mendukung format audio sesuai kemampuan browser.
- Batas durasi rekaman hingga 10 menit.

🎨 Gambar dan Anotasi

- Menggambar langsung menggunakan jari, mouse, atau stylus.
- Alat pena, stabilo, dan penghapus.
- Pilihan warna dan ketebalan goresan.
- Undo goresan.
- Menghapus seluruh gambar.
- Menyimpan gambar ke dalam catatan.

💾 Penyimpanan Lokal

- Menggunakan IndexedDB untuk menyimpan data.
- Penyimpanan catatan tanpa server atau backend.
- Autosave dengan indikator status penyimpanan.
- Penyimpanan folder, pengaturan, dan riwayat versi.
- Informasi penggunaan kapasitas penyimpanan lokal.
- Mendukung penggunaan secara offline setelah aset aplikasi tersedia di perangkat.

🗂️ Backup dan Pemulihan

- Mengekspor data aplikasi ke file JSON.
- Mengimpor dan memulihkan data dari backup.
- Memvalidasi struktur file backup sebelum pemulihan.
- Mendukung ekspor catatan ke format Markdown.
- Menyimpan riwayat versi catatan.
- Melihat dan memulihkan versi catatan sebelumnya.

⚙️ Personalisasi

- Tema terang (Light Mode).
- Tema gelap (Dark Mode).
- Tema mengikuti sistem perangkat (System Theme).
- Pengaturan warna aksen.
- Pengaturan ukuran font editor.
- Mode fokus untuk pengalaman menulis yang lebih minim gangguan.

📱 Progressive Web App (PWA)

- Dapat dipasang pada perangkat yang mendukung PWA.
- Tampilan responsif untuk perangkat mobile dan desktop.
- Mendukung penggunaan melalui browser maupun mode aplikasi mandiri.
- Service Worker untuk penyimpanan aset dan akses offline.
- Ikon aplikasi dan layar peluncuran.
- Pintasan aplikasi untuk membuat catatan baru dan membuka pencarian.

⌨️ Produktivitas

- Pintasan keyboard untuk tindakan tertentu.
- Panel perintah (Command Palette).
- Dialog dan menu kontekstual.
- Navigasi antarhalaman catatan.
- Pemilihan beberapa catatan untuk tindakan kolektif.
- Notifikasi status dan hasil tindakan.

🛠️ Teknologi

- HTML5 — Struktur aplikasi.
- CSS3 — Antarmuka dan desain responsif.
- Vanilla JavaScript (ES Modules) — Logika aplikasi.
- IndexedDB — Penyimpanan data lokal.
- Service Worker — Cache aset dan dukungan offline.
- Web Audio / MediaRecorder API — Perekaman suara.
- Canvas API — Fitur menggambar.
- Progressive Web App (PWA) — Instalasi aplikasi pada perangkat yang kompatibel.

🔒 Privasi dan Data

- Catatan disimpan di penyimpanan lokal browser.
- Tidak memerlukan akun pengguna atau server backend untuk fungsi inti.
- Data dapat diekspor melalui fitur backup.
- Menghapus data browser atau penyimpanan situs dapat menghilangkan catatan yang belum dicadangkan.
- Backup JSON disarankan untuk menjaga keamanan data.
